## Reflection notes

**What?** I reviewed Python features that can support the extraction, validation, transformation and output stages of a data-management pipeline.

**So what?** The exercise showed that formatting, parsing, membership testing and file output perform different jobs. Selecting the correct operation matters because a visually improved value is not necessarily a cleaned or validated value.

**Now what?** In later cleaning activities, I will define the expected data type and validation rule before transforming a field. I will preserve the raw data and check the output so that changes remain reproducible and traceable.
